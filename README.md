# obdkt

Abstraction layer for the ELM327 OBD2 interface to visualize real-time vehicle diagnostics data. Connected to vehicles via USB adapter, with bluetooth support eventually.

## Prerequsites

- USB-capable OBD2 adapter
- Java JRE 21 or newer

## Troubleshooting

If you have issues with connecting, please ensure you are using the correct BAUD rate with your respective OBD2 adapter

## Architecture

> Backend
Kotlin & Ktor

> Frontend
Vanilla HTML/CSS/JS
